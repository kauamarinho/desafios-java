# Exercícios de Java — Encapsulamento

## Objetivo

Praticar a criação de classes, modificadores de acesso, getters, setters e métodos em Java.

## 1. Conta bancária

Crie uma classe `contaBancaria` com os seguintes atributos:

| Atributo | Visibilidade |
| --- | --- |
| `numeroConta` | Privado |
| `saldo` | Privado |
| `titular` | Público |

Implemente métodos **getters e setters** para acessar e modificar os atributos privados.

## 2. Idade da pessoa

Crie uma classe `IdadePessoa` com os seguintes atributos privados:

- `nome`
- `idade`

### Métodos

- Implemente **getters e setters** para acessar e modificar os atributos.
- Adicione um método `verificarIdade` que imprime se a pessoa é maior de idade ou não.

## 3. Produto

Desenvolva uma classe `Produto` com os seguintes atributos privados:

- `nome`
- `preco`

### Métodos

- Implemente **getters e setters** para acessar e modificar os atributos.
- Adicione um método `aplicarDesconto` que recebe um valor percentual e reduz o preço do produto.

## 4. Aluno

Desenvolva uma classe `Aluno` com os seguintes atributos privados:

- `nome`
- `notas`

### Métodos

- Implemente **getters e setters** para acessar e modificar os atributos.
- Adicione um método `calcularMedia` que retorna a média das notas do aluno.

## 5. Livro

Desenvolva uma classe `Livro` com os seguintes atributos privados:

- `titulo`
- `autor`

### Métodos

- Implemente **getters e setters** para acessar e modificar os atributos.
- Adicione um método `exibirDetalhes` que imprime o título e o autor do livro.
