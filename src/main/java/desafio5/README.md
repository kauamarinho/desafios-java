# Desafio — Hora da prática: ArrayList no Java

## Objetivo

Praticar a representação e a manipulação de listas com `ArrayList` em Java.

Neste desafio, serão utilizados os métodos abaixo:

| Método | Finalidade |
| --- | --- |
| `add()` | Adiciona um elemento à lista. |
| `size()` | Retorna a quantidade de elementos da lista. |
| `get()` | Obtém um elemento a partir de sua posição na lista. |
| `toString()` | Representa um objeto como texto. |

As atividades a seguir são práticas e **não obrigatórias**.

## Atividades

1. Crie uma classe `Pessoa` com atributos como `nome` e `idade`.
2. Implemente o método `toString()` na classe `Pessoa` para representar esses atributos em texto.
3. No método `main` da classe `Principal`, crie um `ArrayList<Pessoa>` chamado `listaDePessoas`.
4. Adicione pelo menos três objetos `Pessoa` à lista usando o método `add()`.
5. Imprima o tamanho da lista usando o método `size()`.
6. Imprima a primeira pessoa da lista usando o método `get()`.
7. Imprima a lista completa.

## Resultado esperado

Ao executar o programa, deve ser possível visualizar:

- A quantidade de pessoas cadastradas na lista.
- Os dados da primeira pessoa inserida.
- A representação textual de todas as pessoas cadastradas.

Este README contém somente o enunciado do desafio, sem solução.
